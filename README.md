# One Sentence for a Traveler from 1800

One sentence, at most 200 characters, explaining the modern internet to someone arriving from 1800 — built only from things they already know: a library, a letter, ink drying.

> Imagine a library holding every book ever written, where a letter you write reaches the far side of the world before the ink dries.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`, byte for byte. Node standard library only; no dependencies.
